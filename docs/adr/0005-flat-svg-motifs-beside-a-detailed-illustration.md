# 装飾モチーフはフラットのシルエットで固定し、人物イラストに質感を寄せない

[ADR-0004](./0004-replace-human-svg-with-generated-illustration.md) で人物イラストが生成ラスターになった結果、**画面上に2種類の質感が同居する**ことになった。人物には水彩の粒状感があり、毛糸の編み目・花柄・靴紐まで描き込まれている。一方、装飾モチーフ（木・テント・かぼちゃ・旗ガーランド・月・コウモリ・星・鳥）は [ADR-0001](./0001-decorative-motifs-as-new-inline-svg.md) の通りインライン SVG の単色シルエットである。

実機（Chrome、SP幅390px）で確認したところ、**両者は問題なく共存していた**。ただし「揃っているから」ではなく、**揃っていないから**である。描き込みの差がそのまま「主役＝人物／背景＝風景」という視覚的階層を作っており、これは意図として維持する価値がある。

したがって **SVG 側に水彩風のテクスチャや細部を一切足さない**。これは手抜きではなく設計判断であり、「装飾が人物に比べて簡素すぎる」という理由で後から描き込むべきではない。

## Considered Options

- **SVG フィルタ（feTurbulence 等）で紙目を足す** — 色の CSS 制御は保てるが、フィルタは描画コストが高く（特にモバイル）ブラウザ差も出る。中途半端に寄せると水彩ではなく安っぽいノイズに見える。
- **装飾も画像生成モデルで作る** — 質感は完全に揃うが、ADR-0001 が SVG を選んだ理由（色を CSS 変数で制御できる、揺れ・浮遊のアニメーションが効く）を丸ごと失う。装飾は画面のあちこちに散るため、透過 PNG が増えて転送量も膨らむ。

## Consequences

装飾を描き足す際は**シルエット止まり**とする。大きくする・数を増やすほど人物と競合するため、量にも慎重であるべきで、下部セクション（ABOUT／開催概要／FAQ／CTA）は札とブロブの境界だけで成立させる方針とした。実際、画面端で切れていた装飾を削除した後のほうがむしろすっきり見えている。
