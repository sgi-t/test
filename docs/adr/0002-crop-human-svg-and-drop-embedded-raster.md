# human.svg は埋め込みラスターを削除し viewBox をクロップする

> **この決定は [ADR-0004](./0004-replace-human-svg-with-generated-illustration.md) に置き換わりました。** `human.svg` はクロップせず廃止し、新規生成したラスターイラストに差し替えます。以下の分析は「なぜ元ファイルを使わないのか」の根拠として残します。


`human.svg` は 2.9MB あるが、そのうち **1.67MB（57%）は一度も描画されない**。`<image>` 要素が viewBox の完全に外側（x:-1314, y:-305）に置かれており、SVG ルートの既定のクリップで捨てられているためだ。実際に見えているのは同じ絵をトレースしたベクターパス9本のほうである。さらに可視領域は viewBox `0 0 1024 1536` のうち **y:615〜1152 だけ**で、上40%・下25%が空白。`<img>` は 1024×1536 のボックスを確保するので、レイアウト上も65%が無駄な空箱だった。そこで `<image>` を削除し、viewBox を `0 615 1024 537` にクロップする（約1.26MB、レイアウトボックスは1/3）。

`width` / `height` 属性から想像される寸法と viewBox が一致しなくなるため、事情を知らない読み手には不可解に見える。この ADR はその理由の記録である。

## Consequences

軽量化と同時に、この人物イラストは `opacity: 0.15` の背景装飾をやめ、不透明にしてヒーローの主役として扱う。現状は 2.9MB を透明度15%の飾りに払っており、しかもタイトルと13人の顔が重なって「消し忘れた下書き」に見えていた。ただしこの絵はセピア調（ベージュ〜茶＋オレンジ2色）で、[実測パレット](../../CONTEXT.md)の深緑・くすみ青を含まないため、ポスターの人物の色味とはずれが残る。破棄して新規に描き起こす案もあったが、13人の集合イラスト相当の密度を手描きで再現するのは現実的でないと判断した。
