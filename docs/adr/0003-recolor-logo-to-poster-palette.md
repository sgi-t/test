# ロゴは形を保ったまま、配色だけポスター準拠に差し替える

`logo.svg` の fill は9色 — `#f8d3a7` `#9c97ac` `#f8a42f` `#f87402` `#6c5f91` `#564f70` `#4b2b83` `#442677` `#2e2164` で、内訳は**紫4色＋オレンジ2色＋中間3色**。つまり従来型の「紫×オレンジ」ハロウィン配色であり、[実測パレット](../../CONTEXT.md)の深緑・くすみ青・黄は**1色も含まれていない**。ロゴだけがサイト全体と別系統の配色になるため、形（魔女帽子・おばけ・コウモリ・星・副題を含む一枚絵）はブランド資産として保ったまま、9本のパスの fill をポスター準拠にマッピングし直す（紫4色→深緑4階調、オレンジ2色→コーラル／橙）。

**これは意図的な変更であり、元の配色に戻すべきバグではない。** 既存ロゴの色をそのまま使う案（小さく表示されるので齟齬は目立たないかもしれない）と、ポスターの「まち」緑／「ハロ！」橙の2色使いを Web フォントで新規に組み直す案も検討したが、前者はサイト全体の配色を全面的に入れ替える今回の方針と噛み合わず、後者は既存ロゴのディテールを失う。

## Consequences

[ADR-0001](./0001-decorative-motifs-as-new-inline-svg.md) の通り、9本のパスは色の量子化レベルであってモチーフ単位ではない。したがって fill を差し替える際は**元の9色の明度順を崩さないようマッピングする**必要がある。順序を入れ替えると絵の陰影が反転して破綻する。
