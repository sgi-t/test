# 会場住所だけはポスターより Web を優先する（4-35-45 が正）

[CONTEXT.md](../../CONTEXT.md) の通り、表記が食い違ったときは**ポスターが正**というのが原則である。会場住所はその唯一の例外で、**ポスターの「町田市木曽西4-12-31」が誤り**、旧サイトの **「町田市木曽西4-35-45」が正しい**。

## 根拠

決め手は地理的な照合だった。OpenStreetMap の建物ノード（node 6301868340）と国土地理院の街区レベル位置参照情報を突き合わせると:

| 地点 | 建物ノードからの距離 |
|---|---|
| 木曽西4丁目 **35番** の街区中心 | **6.7 m** |
| 木曽西4丁目 **12番** の街区中心 | **143.3 m** |

建物は物理的に35番の街区内にあり、12番は約140m離れた別の街区である。これは地図会社のデータではなく政府オープンデータによる独立検証なので、最も強い根拠になる。

加えて、住所を掲載している5件（マピオン電話帳、Yahoo!マップ、NAVITIME、町田市バリアフリーマップ、OpenStreetMap）が**すべて 4-35-45 で一致**し、4-12-31 を裏付ける情報源は1件も見つからなかった。「木曽西4-12-31」を完全一致で検索しても、いかなる施設とも結びつかない。

木曽西四丁目は2007年12月1日に住居表示を実施済みで、街区符号は1〜37番まで存在する。**12番も35番も実在する**ため、4-12-31 は「あり得ない住所」ではない。だからこそ気づかれにくい誤記だった。

## 留保

一次情報源（施設の公式表記）は確認できていない。創価学会の公式サイトは道府県中心会館しか掲載しておらず、町田市の公式施設一覧にも民間宗教施設なので載っていない。根拠はすべて地図・電話帳データベースと OSM という二次情報である。また「45」という住居番号そのものは公的台帳で裏が取れていない（2007年の新旧対照表は実施時点で建物があった箇所のみを収録するため、後から付番された可能性はある）。

**確定情報として扱う前に 042-789-5211 へ直接確認することを推奨する。**

## Consequences

**配布済みのポスターに誤った住所が載っている。** 当日の来場者が140m離れた別の街区へ向かう可能性があるため、Web 側を正すだけでは足りない。正誤情報の告知や当日の誘導表示など、サイト外での対応が別途必要になる。

なお会場名は、ポスターの「町田平和会館」を採用している（旧サイトは「創価学会 町田平和会館」）。地図サービス上は「町田平和会館」単独でも解決するため、来場動線への影響はない。
