# 装飾モチーフは既存 SVG から抽出せず、インライン SVG で新規に描き起こす

リポジトリには `logo.svg` と `human.svg` があり、一見するとポスターのモチーフ（コウモリ・おばけ・かぼちゃ・星）が入っているように見えるが、**どちらも Inkscape の「ビットマップのトレース → 複数スキャン（カラー）」出力**で、パスがモチーフ単位ではなく**色の量子化レベル**で分かれている。`logo.svg` の1本のパスには「まち」の文字・コウモリ2匹・星・おばけの輪郭・副題が断片として同居しており、逆にかぼちゃ1個は5〜9本のパスにまたがる（各パスのサブパス数は logo で38〜111、human で216〜349）。どの1本を取り出しても単一モチーフにならないため、**既存アセットからのモチーフ抽出は事実上不可能**と結論した。

## Considered Options

- **ポスター画像から個別に切り出して透過ラスターにする** — 見た目はポスターそのものだが、JPEG 圧縮のにじみごと切り抜くことになり、後から色を変えられず、ファイル数も増える。
- **モチーフを使わず、色面と丸みだけでトンマナを作る** — 最も軽く破綻がないが、ポスターの手作り感が大きく失われる。

## Consequences

新規に描き起こす分、手描きの味はポスターに及ばず素朴な図形寄りになる。その代わり色を CSS 変数で制御でき、軽く、揺れ・浮遊などのアニメーションも効く。なお、ポスターにある木・テント・旗ガーランド・月・雲・鳥は**そもそも既存 SVG のどちらにも存在しない**ため、これらは選択肢に関わらず新規作成が必要だった。
