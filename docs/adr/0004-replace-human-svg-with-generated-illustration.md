# 人物イラストは生成ラスターに差し替え、human.svg は廃止する

[ADR-0002](./0002-crop-human-svg-and-drop-embedded-raster.md) では `human.svg` をクロップして使う方針だったが、採用デザイン（ポスター継承型）のモックアップに実際に置いてみると、**元絵のセピア調（ベージュ〜茶＋オレンジ2色）が[実測パレット](../../CONTEXT.md)の深緑・くすみ青と噛み合わない**ことがはっきりした。しかも [ADR-0001](./0001-decorative-motifs-as-new-inline-svg.md) の通り元絵は色の量子化レベルでパスが分かれたトレース出力なので、**色だけ調整するという逃げ道もない**。そこで画像生成モデルでポスター準拠のシーンイラストを新規に作り、`human.svg` は廃止する。

人数は元の13人から**6人に減らした**。SP幅390pxの帯に13人を並べると1人あたり約30pxとなり、表情も服の柄も潰れて「並んだ棒」にしか見えないため。6人なら1人あたり約65pxが確保でき、実寸でも表情と持ち物（かぼちゃバスケット、猫耳ハット）が判別できる。

## 生成物の後処理（再生成するときはこの手順を踏むこと）

生成された PNG は 2172×724 / 1.4MB で、そのままでは使えなかった。

1. **アルファ1〜31の飽和色ピクセルが約5万個（全体の3.2%）** 混じっていた。肉眼ではほぼ見えないが、縮小時に平均化されて輪郭に赤・黄の色にじみを出す。**32未満を完全透過に落とす**。
2. 人物本体のアルファが251〜254で、完全不透明が0.2%しかなかった。**240以上を255に丸める**。
3. 掃除後にトリミングすると 2172×724 → **1717×698**。外周の大半は1のノイズだった。
4. 縮小前に**地色 `#F7F2EC` に合成してから RGB を縮小**し、アルファは別に縮小して再合成する。透過ピクセルの黒が混ざるハローを防ぐと同時に、縁の色が置き場所の地色側に寄る。
5. WebP 化。760px幅で64KB、1100px幅で102KB。

## Consequences

**素材の質感が2種類混在する。** 装飾モチーフ（木・テント・旗・月）は ADR-0001 の通りインライン SVG なので、そこにラスターの人物が乗る。生成プロンプトで「フラット塗り・グラデーションなし・影なし・輪郭線は極細か無し」を強く指定しているのはこのためで、再生成時にここが緩むと人物だけ浮く。

転送量は `human.svg` の **2.9MB から 64KB（760px幅）へ約98%削減**。しかも現状は opacity .15 の背景装飾だったのに対し、今回は不透明でヒーロー直下の主役として使う。

一方で**イラストは再生成しないと変更できない**。SVG と違って色や人数を後から CSS で動かせないので、パレットを変える判断が入ったら作り直しになる。
